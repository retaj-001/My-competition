# نسخة Supabase التطويرية

لم يُغيّر `app.js` ولا الموقع المنشور؛ ما زال Firebase هو مسار الرجوع. النسخة الجديدة في `app.supabase.js` وتحافظ على DOM والتفاعل والتصميم نفسه.

1. انسخ `supabase-config.example.js` إلى `supabase-config.js` وأدخل URL وanon key العامين.
2. في نسخة تطوير من `index.html` غيّر `app.js` إلى `app.supabase.js`.
3. اختبر الاستعلام كل ثانيتين، وحالة البيانات القديمة، والجوال، وكل النوافذ التفصيلية.
4. لا تحوّل `index.html` المنشور إلا بعد نجاح إدخال ESP32 الحقيقي والمقارنة مع Firebase.

الاستعلام العام يعيد الحرارة والتسارع والسرعة والأقمار فقط. الإحداثيات الدقيقة تُحجب افتراضيًا؛ ولا يعيدها `latest_authorized_reading` إلا لمستخدم مسجل ومربوط بالجهاز في `device_viewers`.
