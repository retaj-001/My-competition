# خُطى — لوحة المراقبة المباشرة

تعرض هذه الصفحة آخر قراءة حقيقية من جهاز `khuta-esp32` في Firebase Realtime Database. تستخدم الصفحة تسجيل دخول Firebase مجهولًا للقراءة فقط، بينما تسمح قواعد القاعدة بالكتابة لحساب الجهاز المخصص وحده.

## السلوك

- تستمع الصفحة إلى `/devices/khuta-esp32/live` عبر `onValue` وتُحدّث المؤشرات دون إعادة تحميل.
- تُعرض «غير متاح» للحقول المفقودة أو null.
- تصبح القراءة «قديمة» إذا مضى أكثر من 10 ثوانٍ على timestamp الخادم، مع إبقاء آخر قيمة ظاهرة بوضوح.
- لا توجد بيانات أو رسوم عشوائية. الرسم التفصيلي مبني فقط من القراءات الحقيقية المستلمة منذ فتح الصفحة.
- إحداثيات GPS لا تظهر إلا عند توفر خط العرض والطول، ويظهر عندها رابط OpenStreetMap.

## Firebase

ملف `firebase.json` يشير إلى `database.rules.json`. للنشر من ويندوز بعد تسجيل الدخول:

```powershell
firebase deploy --only database --project khuta-live-monitor
```

تهيئة Firebase Web الموجودة في `app.js` هي تهيئة عميل عامة مطلوبة في المتصفح، ولا تحتوي كلمة مرور أو مفتاح إدارة أو حساب خدمة.
